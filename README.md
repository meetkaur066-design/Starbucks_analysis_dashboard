# ☕ Starbucks Analytics Dashboard

## 📌 Project Overview

An interactive Starbucks Analytics Dashboard built using **Microsoft Power BI** to explore global store distribution and beverage data through visualizations, KPI cards, and interactive filters.

## 🎯 Project Objectives

- Analyze Starbucks' global store presence.
- Explore beverage categories and caffeine content.
- Identify the top 5 highest-caffeine beverages.
- Highlight key metrics using KPI cards.
- Enable interactive data exploration through filters.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- DAX (Data Analysis Expressions)
- Data Analysis & Visualization

## 📊 Dashboard Features

- **Global Presence:** Visualizes Starbucks' geographical distribution.
- **KPI Cards:** Summarizes key metrics and insights.
- **Beverage Analysis:** Explores coffee and beverage categories.
- **Top 5 Caffeine Analysis:** Highlights beverages with the highest caffeine content.
- **Interactive Filters:** Allows users to explore data dynamically.
